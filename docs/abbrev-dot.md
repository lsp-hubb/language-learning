# 英文句点误判问题

## 问题描述

`findSentenceBoundaries()` 用于按 `.` 分割英文句子，但英文中存在大量非句号用途的 `.`：

- **缩写点**：`Mr.` `Dr.` `Jr.` `U.S.` `a.m.` `etc.`
- **小数点**：`3.14` `0.5`
- **省略号**：`...`

## 影响范围

句子分割结果直接影响**翻译句子高亮**和 **r 键长难句标注**的索引对齐（英文第 n 句 ↔ 中文第 n 句）。

## 判定规则

只将满足以下条件的 `.` 视为句子边界：

```
后面是 → 空格 / 引号("' "'') / 右括号 / 行尾 / 换行 / 大写字母A-Z
+ 且 "." 前的单词不是常见缩写
```

**2026-07-04 更新（1）**：支持 Unicode 弯引号（`"` U+201C、`"` U+201D、`'` U+2018、`'` U+2019），
解决外刊文本中智能引号导致的句点漏判问题。

**2026-07-04 更新（2）**：`.` 后紧跟大写字母 `[A-Z]` 也视为句子边界（如 `2020.Large`），
因为缺少空格通常是排版/OCR 问题，但 `isAbbrevDot` 仍会二次校验排除缩写。

### 缩写白名单

```js
mr, mrs, ms, dr, st, jr, sr, vs,
etc, inc, ltd, ave, dept, est, govt,
jan, feb, mar, apr, jun, jul, aug, sep, oct, nov, dec
```

+ **单字母缩写**统一跳过（`U.S.`、`a.m.`、`p.m.`）
+ **数字+字母组合**不会被误判为单字母：`isAbbrevDot()` 向后匹配 `[A-Za-z0-9]` 而非 `[A-Za-z]`，确保 `1600s.` 提取出完整单词 `1600s`，非单字母故不被跳过
+ **弯引号视为单词内字符**：`isAbbrevDot` 的向后遍历包含 `\u2018\u2019\u201C\u201D`，避免 `couldn't.` 被误判为单字母缩写

### 示例对照

| 文本 | 判定 | 原因 |
|------|------|------|
| `killed."` | ✅ 句号 | 后面 ASCII 引号，单词正常 |
| `killed."` | ✅ **句号** | 后面 Unicode 左双引号 |
| `ended. Next` | ✅ 句号 | 后面空格，`ed` 不在白名单 |
| `Jr., was` | ❌ 跳过 | 后面逗号 |
| `Mr. Smith` | ❌ 跳过 | `mr` 在白名单 |
| `U.S. ` | ❌ 跳过 | `S` 为单字母 |
| `etc. ` | ❌ 跳过 | `etc` 在白名单 |
| `3.14` | ❌ 跳过 | 后面是数字 |
| `...` | ❌ 跳过 | 后面是 `.` |
| `a.m. ` | ❌ 跳过 | `m` 为单字母 |
| `1600s. ` | ✅ **句号（已修复）** | `1600s` 含数字，非单字母，不在白名单 |
| `novel."It` | ✅ **句号（已修复）** | 后面 Unicode 左双引号 `\u201C` |
| `couldn't.` | ✅ 句号 | 弯引号纳入单词字符，`couldn't` 非白名单 |
| `2020.Large` | ✅ **句号（已修复）** | 后面大写字母 `L`，`2020` 非缩写 |

## 局限

- 白名单可能遗漏某些领域特有缩写（如法律引文 `v.`、学衔 `Ph.D.`）
- 新缩写需手动添加至 `ABBREV_SET`
- 完美分割需要 NLP 句点消歧，当前启发式规则覆盖常见场景
